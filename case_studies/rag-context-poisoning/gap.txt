Attack class: indirect prompt injection via retrieval-augmented
generation (RAG) context. The injection vector is the corpus the
agent retrieves from — wikis, ticket threads, crawled web pages, or
any data source the attacker can write to. Parent class: OWASP
LLM01 (Prompt Injection).
